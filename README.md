## Spark quickstart notebook

`spark_quickstart.ipynb` runs PySpark in local mode: DataFrames, aggregations, pivots,
Spark SQL, window functions, an RDD word count, and a query plan. Saved outputs come from a real run on Spark 4.2.0.

```bash
# Requires Java 17+
pip install -r requirements.txt
jupyter notebook spark_quickstart.ipynb
```
